# v0.8.1 Dashboard Operator Answers

MorningstarModbusFrontend v0.8.1 integrates the Operator Answers layer directly into the main Site Overview while retaining the complete `/site/questions` workspace introduced in v0.8.

## Goal

The Site Overview already answers many questions indirectly through telemetry cards, power flow, health, forecast, and navigation. v0.8.1 makes the highest-value answers explicit on the dashboard so operators do not need to know which specialist page to open first.

The dashboard is intentionally curated instead of rendering all 28 canonical questions at once.

## Dashboard organization

The Site Overview adds four groups:

### Priority

- What needs attention first?
- Are there active incidents?
- How is the site doing right now?

### Live state

- Are all controllers online?
- How much solar power is arriving right now?
- What is battery voltage right now?
- What charge stage is the site in?

### Today & outlook

- Is solar input normal for this time of day?
- What is projected total solar input by end of day?
- Are we ahead of or behind the normal solar trajectory?
- Will the controllers likely reach Float today?

### Evidence confidence

- Are key measurements conflicting, unsupported, or temporarily unavailable?
- How much history supports the current solar outlook?
- How accurate has the local forecast model been?

Every compact answer retains its existing status and links to the authoritative evidence workspace.

## Full Questions workspace

`/site/questions` remains the comprehensive investigation surface:

- all 28 canonical questions;
- full-text search;
- category filters;
- expandable evidence;
- matched-time 7-day performance comparisons;
- links into Forecast, Day Lab, Replay, Operations Intelligence, Power Flow, History, and Controllers.

The Site Overview therefore acts as the high-signal starting point while the Questions workspace remains the complete catalog.

## Shared evidence architecture

v0.8.1 extracts Operator Answers data acquisition into a shared `useOperatorAnswersData` hook. Both the dashboard and full Questions workspace now use the same deterministic answer builder and backend resources.

This prevents the two surfaces from developing different answer semantics.

The dashboard calls the hook with historical comparisons disabled. It still consumes current telemetry, system health, health score, incidents, local baseline, forecast, and forecast accuracy, but does not request the four 7-day 15-minute history series used by the full Questions workspace. This keeps the main dashboard comparatively lightweight.

## Evidence boundaries

The existing v0.8 semantics remain unchanged:

- no LLM-generated diagnosis;
- no controller writes or configuration changes;
- no inferred battery SOC without supporting instrumentation;
- no conversion of controller charge current into battery net current;
- no interpolation through missing historical telemetry;
- no promotion of time correlation into causation;
- unsupported, unavailable, conflicting, and unknown evidence remain distinguishable.

## Version

The frontend development version is `0.8.1`.
