# MorningstarModbusFrontend v0.3.1

Published August 16, 2026.

Release: https://github.com/hasnocool/MorningstarModbusFrontend/releases/tag/v0.3.1

## What this release represents

v0.3.1 is the first published frontend release that bundles the controller-native/site-native architecture introduced after v0.1.0 together with the Operations Intelligence layer and the restored historical telemetry/wall-display operator surfaces.

## Included changes

### Controller-native site operations

- immutable `controller_uid` routing for physical-controller workspaces;
- site overview, power flow, energy ledger, normalized history, events, topology, and component graph;
- controller-scoped latest telemetry, history, statistics, gap/coverage analysis, energy reconciliation, polling diagnostics, and exports;
- SSE-driven cache invalidation with polling fallback;
- legacy device-ID URL compatibility redirects.

### Operations Intelligence

- site and controller incident timelines;
- transparent decomposed health scores;
- source-backed expected-versus-observed evidence;
- local P10/median/P90 production baselines;
- 24-hour charge-cycle summaries;
- live incident-opened/updated/resolved refresh through system SSE.

### v0.3.1 regression restoration

- restores the advanced multi-series Apache ECharts telemetry-history page at `/controllers/:controllerUid/telemetry-history`;
- keeps `/controllers/:controllerUid/history` as the separate History Integrity/evidence-recovery view;
- preserves 1h/6h/24h/7d/30d ranges, selectable resolution, zoom, min/max envelopes, state transitions, and window statistics;
- makes the historical chart controller-native so connection path changes do not split the physical controller's history;
- restores Wall display as an explicit controller navigation item while retaining `/display/controller/:controllerUid` and the top-bar shortcut.

## Compatibility

The frontend remains read-only. Register-map, device-intelligence, and profile-validation views still resolve the controller's active raw `device_id` where the backend exposes those engineering resources device-scoped. Controller lifetime telemetry/history/energy/intelligence routes remain keyed by immutable `controller_uid`.

The v0.3.x frontend is intended for MorningstarModbusAPI v0.6+ plus the current site-intelligence endpoints used by Operations Intelligence.

## Validation

The telemetry-history/wall-display restoration passed the full frontend CI surface before merge: ESLint, strict TypeScript, Vitest, production build, bundle-size guard, and Playwright E2E. The release workflow separately validated that the `release/v0.3.1` branch matched `package.json` version `0.3.1` before publishing the GitHub release.
